# Evals

Supporting tags and branches for demo evals have been pushed to the github repository.

See the /evals directory for instructions on how to run the eval, and also log data from runs.

## Base Tags

Create a branch based on one of these tags if you want to create a new eval scenario.

- [no-adrs](https://github.com/acmelabsai/acme-admin/releases/tag/no-adrs) - before ADRs were committed to the codebase
- [adrs](https://github.com/acmelabsai/acme-admin/releases/tag/adrs) - with ADRS committed to the codebase
