# Adopt React Testing Library with Vitest for Component and Unit Testing: Typescript Utilities Hooks

These rules are ALWAYS ACTIVE for all TypeScript utilities, hooks, stores, and React components in the codebase.

### Rules

- **R-RTL-001** MUST: All TypeScript utilities, hooks, and stores MUST have corresponding test files using the .test.ts extension co-located with the source file.
- **R-RTL-002** MUST: All React components (.tsx files) MUST have corresponding .test.tsx files co-located with the source file.
- **R-RTL-003** MUST: Test files MUST use React Testing Library for component testing and follow user-centric testing patterns.
- **R-RTL-004** MUST: The test suite MUST execute successfully with the vitest run command and all tests MUST pass.
- **R-RTL-005** MUST: Package.json MUST contain both @testing-library/react and vitest as dependencies.
- **R-RTL-006** MUST: CI/CD pipeline MUST include a test execution step that blocks merges on test failures or coverage drops below configured thresholds.
- **R-RTL-007** SHOULD: Test files SHOULD be co-located with source files to improve discoverability and maintainability.
- **R-RTL-008** SHOULD: Shared test utilities and custom render functions (e.g., renderWithProviders) SHOULD be created to handle common setup like Redux stores, React Router, and theme providers.
- **R-RTL-009** MAY: Exceptions for prototype/spike code explicitly marked as experimental (EXC-001) or pure presentational components with no logic (EXC-002) MAY be documented and approved by tech lead.

### Verify

```bash
# Find source files missing corresponding test files
find src -type f \( -name '*.tsx' -o -name '*.ts' \) ! -name '*.test.*' ! -name '*.spec.*' -exec sh -c 'test -f "${1%.tsx}.test.tsx" -o -f "${1%.ts}.test.ts" || echo "Missing test: $1"' _ {} \;

# Verify testing dependencies are installed
grep -q "@testing-library/react" package.json && grep -q "vitest" package.json && echo "Testing dependencies found"

# Run test suite with coverage report
vitest run --coverage --reporter=json --reporter=text

# Count test files in the codebase
grep -l "describe\|test\|it" src/**/*.test.{ts,tsx} 2>/dev/null | wc -l
```

**Accept when:**
- All component files (.tsx) have corresponding .test.tsx files with at least one test case
- All utility and hook files (.ts) have corresponding .test.ts files with at least one test case
- Test suite executes successfully with vitest run command and all tests pass
- Package.json contains both @testing-library/react and vitest as dependencies
- CI/CD pipeline includes test execution step that blocks merges on test failures
- Code coverage reports are generated by Vitest and reviewed during pull request process

<enforcement>
Claude Code MUST NOT skip or defer verification of these rules. All pull requests MUST pass the verify commands before merging. Violations MUST be addressed or documented as exceptions with tech lead approval.
</enforcement>
